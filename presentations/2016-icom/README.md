# Representation of Distinct Dimensions of Episodic Retrieval Along the Hippocampal Long Axis

**Poster Presentation** ([View Poster](./2016-chow-icom.png)) | International Conference on Memory (ICOM) | 2016 | Budapest, Hungary

**Fellowship Award:** National Science Foundation Graduate Research Fellowship Program

## Executive Summary

* **Problem:** The hippocampus is critically involved in episodic memory retrieval, including processing diverse memory attributes such as self-referential details, novelty, and temporal sequence. However, it is unknown how these dimensions are simultaneously mapped along its functional anterior-to-posterior axis during real-world memory retrieval. *Does activation of different memory characteristics occur in different hippocampal areas?*
* **Approach:** Employed a fully-crossed, 3-factor fMRI experimental design utilizing naturalistic event sequences captured from participants' lives over 3 weeks via wearable digital cameras. General linear model (GLM) parameter estimates were extracted from 6 bilateral hippocampal sub-regions as *measures of activation to detect regional differences*, and generalized context-dependent psychophysiological interaction (gPPI) analyses were conducted to *map the functional connectivity of the anterior and posterior hippocampus*.
* **Takeaway:** Hippocampal long axis regions display distinct functional specialization and connectivity profiles. **Anterior hippocampal regions** responded to novelty and temporal intactness (*potentially reflecting memory search and construction mechanisms*), whereas **intermediate and posterior hippocampal regions** were driven by personally experienced events (*potentially reflecting retrieval and elaboration mechanisms*).

## Executive Summary

* **Problem:** The hippocampus processes diverse memory dimensions (novelty, temporal sequence, self-relevance), but how these distinct attributes are simultaneously mapped and coordinated along its functional anterior-to-posterior axis in real-world memory retrieval was unknown.
* **Approach:** Designed a fully-crossed, 3-factor fMRI paradigm leveraging 3 weeks of naturalistic, wearable-camera sensor streams per participant. Extracted GLM parameter estimates across 6 bilateral anatomical sub-regions (L1–L6, R1–R6) and mapped context-dependent functional connectivity using gPPI ($p < 0.05$ corrected).
* **Takeaway:** Identified a functional dissociation along the long axis: **anterior regions** exhibited significant linear trends for novelty and temporal sequence reconstruction (supporting memory search/construction), whereas **intermediate and posterior regions** exhibited quadratic effects driven by personally experienced events (supporting retrieval/elaboration) with distinct Default Mode Network coupling.

## Technical Methodologies
*As the lead researcher, first author, and NSF GRFP Fellow, I designed and executed the end-to-end experimental, data ingestion, and analytical workflows:*

* **Experimental Architecture & Ingestion:** Engineered a 3-phase longitudinal paradigm using passive wearable camera sensors to capture unstructured, real-world data over 3 weeks (120 event sequences per participant). Programmed custom scan-synchronized 4-choice response tasks and stimulus delivery in **MATLAB**.
* **Statistical & Time-Series Modeling:** Built an end-to-end pipeline to clean 4D neuroimaging time-series, segment anatomical regions of interest (Harvard-Oxford atlas), estimate multivariate GLM parameters, apply Bonferroni corrections, and compute generalized psychophysiological interaction (gPPI) functional connectivity networks.
* **Data Visualization:** Engineered comparative figures and anatomical spatial maps translating multidimensional statistical interactions and network correlations into clear visual summaries.
